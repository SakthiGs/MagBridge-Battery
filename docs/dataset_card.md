# Dataset Card: MagBridge-Battery v1.0

## Summary

MagBridge-Battery is a synthetic dataset of magnetic-field time-series signatures for lithium iron phosphate (LFP) cells. It is produced by a bridging procedure that conditions the magnetometry waveforms from the **Mohammadi–Jerschow OSF archive** on electrochemical state labels (voltage, SOC, SOH, chemistry) drawn from the **PulseBat** dataset. The result is a labelled corpus suitable for benchmarking sequence models on battery state estimation, anomaly detection, and out-of-distribution extrapolation.

- **Version**: 1.0
- **Schema**: 1.0
- **Generation date (UTC)**: 2026-05-16T14:52:12Z
- **Bridge version**: v1.3 (`MAGBRIDGE_V1_0_PHASE2_FIXED_20260515`)
- **Total samples**: 6,760
- **Per-sample sequence length**: 100 time-steps
- **Signal channels**: 6 (`B_s1Y`, `B_s1Z`, `B_s2Y`, `B_s2Z`, `B_s1C5`, `B_s2C6`)
- **Auxiliary channel**: `time_norm` (constant reference grid)
- **Licenses**: CC-BY-4.0 (data), Apache-2.0 (code)

## Composition

### 5,600 clean grounded samples
PulseBat-conditioned magnetic signatures across the in-distribution voltage range. Carry full labels (`voltage`, `soc`, `soh`, `chemistry`, `second_life_class`) and a per-row `u_features` vector. `anomaly_subtype = "none"`, `anomaly_flag = False`, `anomaly_severity = 0`.

### 600 synthetic anomaly samples
Generated by applying a controlled perturbation to a clean parent sample. Each anomaly row carries `parent_sample_id` pointing at its clean parent.

| Subtype                  | n   | Perturbation                                                                |
|--------------------------|-----|-----------------------------------------------------------------------------|
| `sensor_dropout`         | 150 | One sensor's channels are zeroed/attenuated over a sub-window                |
| `calibration_drift`      | 150 | Slow additive drift across the sequence                                      |
| `temporal_warp`          | 150 | Nonlinear re-sampling along the fixed `time_norm` grid (median Δ ≈ 13.4 nT)  |
| `periodic_interference`  | 150 | Sinusoidal interference added to one or more channels                        |

### 560 Regime-B extrapolation samples
Low-voltage out-of-distribution samples at three anchor voltages outside the in-distribution range:

| `nearest_anchor` | n   |
|------------------|-----|
| 2.54 V           | 183 |
| 2.81 V           | 178 |
| 3.00 V           | 199 |

By design, Regime-B samples have `soh = NaN`, `u_features = NaN`, `second_life_class = NaN`. They are intended for **anomaly detection** and **OOD evaluation**, not for SOH regression.

## Schema

### Identifiers and provenance

| Column                | Type   | Description                                                            |
|-----------------------|--------|------------------------------------------------------------------------|
| `sample_id`           | str    | Globally unique. Format encodes regime and anomaly subtype.            |
| `parent_sample_id`    | str / null | For synthetic anomalies, points to the clean source sample.        |
| `cell_id`             | str    | Physical PulseBat cell of origin (used by `by_cell_primary` split).    |
| `generation_seed`     | int    | RNG seed used to produce this sample.                                  |
| `bridge_version`      | str    | Bridge code version (e.g. `v1.3`).                                     |
| `bridge_config_hash`  | str    | SHA-256 hash of the `BridgeConfig` hyperparameters (12 hex chars). Does not cover full `generation_config.yaml` (sample counts, anomaly subtype distribution); see `manifest.json` for the full provenance fields. |
| `schema_version`      | str    | Currently `1.0`.                                                       |

### State labels

| Column              | Type    | Description                                                                  |
|---------------------|---------|------------------------------------------------------------------------------|
| `voltage`           | float   | Open-circuit voltage (V) at the sample condition.                            |
| `soc`               | float   | State of charge (%, 0–100).                                                  |
| `soh`               | float / NaN | State of health, in [0, 1]. **NaN for Regime-B by design.**             |
| `chemistry`         | str     | Cell chemistry (LFP).                                                        |
| `regime`            | str     | `grounded` or `extrapolation`.                                        |
| `nearest_anchor`    | float   | Voltage of the closest training anchor; defines Regime-B subgroups.          |
| `u_features`        | array / NaN | Latent electrochemical feature vector. NaN for Regime-B.                |
| `second_life_class` | str / NaN | Coarse retirement / second-life category derived from SOH: `reuse` if SOH > 0.85, `recondition` if SOH ≤ 0.85. NaN for Regime-B. |

### Anomaly labels

| Column              | Type   | Description                                                                  |
|---------------------|--------|------------------------------------------------------------------------------|
| `anomaly_flag`      | bool   | `True` iff this row is anything other than `none`.                           |
| `anomaly_subtype`   | str    | One of `none`, `sensor_dropout`, `calibration_drift`, `temporal_warp`, `periodic_interference`, `low_voltage_regime_B`. |
| `anomaly_origin`    | str    | Generator pathway that produced the anomaly.                                 |
| `anomaly_severity`  | float  | Magnitude of the perturbation (>0 for non-clean, =0 for clean).              |

### Signal channels

Each is a length-100 float array per row.

| Channel    | Sign     | Notes                                                                       |
|------------|----------|-----------------------------------------------------------------------------|
| `B_s1Y`    | signed   | Sensor 1, Y component                                                        |
| `B_s1Z`    | signed   | Sensor 1, Z component                                                        |
| `B_s2Y`    | signed   | Sensor 2, Y component                                                        |
| `B_s2Z`    | signed   | Sensor 2, Z component                                                        |
| `B_s1C5`   | **signed** | OSF channel-5 (NOT a strict magnitude — negatives are real)                |
| `B_s2C6`   | **signed** | OSF channel-6 (NOT a strict magnitude — negatives are real)                |
| `time_norm`| —        | Length-100 vector of evenly spaced values in [0, 1]. **Identical across all samples.** Included for loader convenience. |

### A note on `B_s1C5` / `B_s2C6`

The OSF archive labels these channels "Mag", which is misleading: the values are signed and can be negative. In MagBridge-Battery they are renamed `C5` / `C6` to make this explicit. Verified negative content in v1.0:

| Column   | Rows with negative entries | Total negative entries | Min value |
|----------|----------------------------|------------------------|-----------|
| `B_s1C5` | 123                        | 921                    | −80.47    |
| `B_s2C6` | 86                         | 959                    | −94.08    |

If your model requires a non-negative magnitude, derive it as `sqrt(B_s1Y² + B_s1Z²)` (and similarly for sensor 2) rather than treating `C5` / `C6` as magnitudes.

### A note on `time_norm`

`time_norm` is a constant reference grid (the same 100-point vector for every sample). It is stored per-row only as a convenience for loaders that expect a per-sample time axis. Dropping it loses no information. The `temporal_warp` anomaly perturbs the *signal values* on this fixed grid; it does **not** export an irregular per-sample timebase.

## Splits

### `by_cell_primary` (primary benchmark split)

| Subset | Samples | Cells |
|--------|---------|-------|
| train  | 4,507   | (cell-disjoint) |
| val    | 1,074   | (cell-disjoint) |
| test   | 1,179   | (cell-disjoint) |

Verified guarantees:
- Cell overlap across subsets: **0**
- Parent-child cross-split leakage: **0**
- Sample-ID overlap: **0**

**Use this split for every reported result.**

### `by_record_optimistic_baseline` (leaky baseline)

Quantified leakage:
- 59 cells appear in more than one subset
- 292 (clean parent, anomaly child) pairs are split across subsets

A model trained on this split will appear artificially strong. **Do not report its numbers without explicitly labelling them as the optimistic / leaky baseline.**

## Intended uses

- Benchmark **state-of-health (SOH) regression** on `anomaly_subtype = none` samples.
- Benchmark **anomaly detection** on the 600 synthetic anomalies plus the 560 Regime-B extrapolation samples.
- Study **OOD extrapolation** via the Regime-B subgroups at 2.54 / 2.81 / 3.00 V anchors.
- Compare **leakage-free vs. leaky split** behaviour by training on both splits and reporting the gap.

## Out-of-scope uses

- SOH regression on Regime-B samples (`soh` is NaN by design).
- Treating `B_s1C5` / `B_s2C6` as physical magnitudes.
- Treating `time_norm` as per-sample timing information.
- Cross-chemistry transfer claims — only LFP is represented.

## Known caveats

1. **Bridging is synthetic.** Signals are conditioned on real electrochemical labels but pass through a synthetic bridge (`bridge_version v1.3`). Results do not directly extrapolate to raw, unbridged magnetometry without explicit calibration.
2. **`time_norm` is constant.** As described above. Documented, not a bug.
3. **Regime-B carries no SOH.** By design — Regime-B is the OOD/anomaly track.
4. **The optimistic split is leaky.** By design — shipped for contrast only.

## Integrity verification

Recompute SHA-256 over every shipped file and compare against `checksums.sha256`:

```bash
sha256sum -c checksums.sha256
```

All entries should report `OK`. The manifest also pins upstream-source hashes (`osf_data_hash`, `pulsebat_data_hash`) for tracing back to the original archives.
